# 小镇青年模拟器（原型）

骑着小电驴在一个虚构的中国小镇「青石镇」里自由转悠。风格偏写实但朴素：瓷砖贴面的自建房、卷帘门底商、红底黄字的招牌、头顶乱拉的电线、楼顶的太阳能热水器，还有广场上跳广场舞的阿姨们。

## 运行

浏览器的 ES Module 不能直接从 `file://` 加载，需要起一个本地静态服务器：

```bash
cd town
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

不需要安装依赖，Three.js 已经放在 `lib/` 里（r186，MIT 协议）。

## 操作

| 按键 | 作用 |
| --- | --- |

手机上会显示触屏按钮。

## 镇上有什么

- **人民路 × 建设路**：主干道十字路口，有红绿灯，车会停
- **文化广场**：人民路边，阿姨们在跳广场舞（靠近能听到音乐）
- **农贸市场**：人民路东段，蓝色铁皮棚子，可以骑进去
- **中心小学**：西北角，有操场和跑道
- **镇政府**：建设路边，院子里有旗杆
- **青溪河**：镇子南边，有滨河步道和两座桥，过桥是河南村和田地
- 外围是农田、油菜花、大棚、鱼塘、杨树和农家自建房

路上有汽车、面包车、农用车、电动三轮和电动车，会沿车道行驶、在路口转弯、跟车减速，被你挡住会按喇叭。

## 代码结构

```
town/
  index.html        页面和 HUD
  css/style.css
  lib/              three.js
  js/
    main.js         渲染器、灯光、天空、时间段、相机、主循环
    layout.js       道路、街区、特殊地块的平面布局
    world.js        根据布局生成场景：路面、标线、楼房、招牌、河、桥、田、道具
    textures.js     所有贴图都用 canvas 程序化绘制（立面、门面、招牌图集等）
    models.js       助动车、骑手、车辆、行人、树、路灯等模型
    scooter.js      玩家助动车：运动学模型、过弯侧倾、碰撞
    traffic.js      NPC 车辆：车道、路口转弯、跟车、红绿灯
    peds.js         行人、广场舞
    physics.js      2D 碰撞（AABB + 圆）和地面高度
    hud.js          小地图、速度表
    input.js        键盘、触屏、鼠标
    audio.js        WebAudio 合成的电机声、喇叭、广场舞音乐
```

整个镇子用固定种子随机生成，每次打开都一样。改 `world.js` 里的种子就能换一个镇子。
